# Battery Guardian

Create a professional, realistic, production-style web dashboard for an IoT-based EV scooter battery health monitoring and early fault detection system.

PROJECT TITLE:

"IoT-Based EV Scooter Battery Health Monitoring & Early Fault Detection System"

PRODUCT/WEBSITE NAME:

"BatteryGuard"

IMPORTANT:

The website must NOT look like a generic AI-generated dashboard, SaaS template, or futuristic cyber-security UI.

Use the attached/reference dashboard design as the primary visual inspiration.

Keep the same overall design language:

- Clean white dashboard

- Soft light-gray/lavender background

- Purple/lavender accent colors

- Left vertical sidebar

- Rounded cards

- Subtle shadows

- Clean typography

- Spacious layout

- Minimal icons

- Small professional illustrations

- Right-side information panel

- Card-based organization

- Professional academic/industrial IoT product appearance

DO NOT redesign the interface into a completely different style.

Do NOT use:

- excessive gradients

- neon colors

- glowing effects

- excessive animations

- huge AI illustrations

- futuristic sci-fi elements

- excessive glassmorphism

- random 3D objects

- unnecessary charts

- generic "AI Powered" marketing text

The website should look like a real EV battery monitoring product developed by an engineering/IoT company.

26. IMPORTANT TECHNICAL RULE

==================================================

Do not present demo values as actual measurements.

Add a subtle:

"Demo Data"

indicator while using mock data.

The architecture must make it possible to replace demo values with actual ESP32 sensor data later.

The system is an additional monitoring and early-warning layer alongside the existing BMS.

Do not claim that it replaces the BMS.

Do not claim guaranteed fire prevention or guaranteed battery failure prediction.

==================================================

27. FINAL DASHBOARD PRIORITY

==================================================

The main dashboard should immediately answer these five questions:

1. Is the battery online?

2. How healthy is the battery?

3. Is anything abnormal?

4. When was it last serviced / when is the next service?

5. What important notifications require attention?

Do not overcrowd the main dashboard.

Detailed information should be available through the sidebar pages.
